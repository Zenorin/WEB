# China Sourcing Operations Model

## Use when
- Documenting or implementing sourcing/OEM/logistics operations.
- Turning operations into customer workspace status and admin tasks.
- Separating confirmed capabilities from future operations.

## Operations stages
1. Intake: URL, idea, quantity, sales channel, target margin, required services.
2. Supplier discovery: supplier candidate, MOQ, unit cost, lead time.
3. Quote: product cost, domestic China freight, service fee, packaging/labeling, inspection, international freight, customs assumptions.
4. Sample: sample order, photo/video evidence, approval or revision.
5. Production: PO, deposit, production schedule, inspection gate.
6. China warehouse: receipt, quantity check, defect/photo evidence, repack/label/barcode.
7. Compliance support: KC/origin/customs responsibility and evidence placeholders.
8. Shipping/inbound: air/sea/express/domestic/Coupang inbound preparation.
9. Completion: final evidence, costs, unresolved claims.

## Required workflow
- Do not present a planned capability as already operational.
- Define evidence artifact for each customer-visible status.
- Define blocked states for supplier, MOQ, price, compliance, production, inspection, shipping, and platform inbound issues.

## Handoff
- Report changed files, commands run, PASS/FAIL results, remaining risks, rollback note, and personal input needs.
- Cite project paths, not copied reference content.
