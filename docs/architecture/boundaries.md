# Architecture Boundaries

- Reference pages are read-only. Extract roles, IA, flows, service taxonomy, and conversion logic only.
- Do not copy source code, HTML, CSS, JavaScript, images, icons, logos, slogans, exact marketing copy, hidden text, tracking snippets, cookies, sessions, or credentials from reference pages.
- Do not delete existing behavior without role trace, replacement, migration, or explicit approval.
- Do not claim regulated services such as KC certification, origin work, customs agency, or Coupang inbound responsibility unless the operational responsibility is explicitly modeled.
- Real secrets, API keys, hosting credentials, domain logins, customer data, cookies, and session values must stay out of repo docs, AGENTS, SKILL files, command queues, and .env.example.
- Use clean-room role reports as implementation authority, not competitor/reference implementation.
- For this project, apps/web, apps/api, packages/contracts, docs/product, docs/planning, and tools/reference-analysis are active first. apps/extension and packages/collectors are deferred unless a separate URL-analysis/collection slice is approved.
